# The outside review loop for Persian prose

The solo process (writing-style.md, Part 5) stays the base. Add this loop when
the text ships — to a client, a boss, or a public channel:

1. **Prime before writing.** Re-read the class rules (writing-style.md, T13)
   — and any locally kept caught examples — before composing. Examples anchor
   the register better than descriptions.
2. **Compose natively** (Part 5, step 2), then run Part 5's audit unchanged.
3. **Cross-family ear.** A model from a different family than the writer
   reviews the text against the classes. A same-family reviewer passed this
   exact failure mode twice in measurement — family, not size, is what buys
   independence here.
4. **Arbitrate every flag — a flag is not a verdict.** A flag on a locally
   blessed form is rejected; a flag matching a class is fixed; an unmatched
   flag is fixed and recorded as a new locally kept example. In measurement
   the ear flagged a blessed form while catching every real defect; only the
   class/example lookup cleared it.
5. After any style fix, recheck the text against the facts per the skill's
   claim discipline (SKILL.md, writing rule 6) — naturalization must not
   trade against faithfulness.
